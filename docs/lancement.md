# Lancement — FlowCommerce

## Hébergement
- API : Render, Web Service Docker, Root Directory `apps/api`, région Frankfurt, health check `/api/v1/health`.
- Base : Neon (Frankfurt). Gratuit (~0,5 Go) au début, payant dès les premiers clients payants.
- Coûts estimés / mois : 50–300 vendeurs ≈ 13–20 $ · 300–2 000 ≈ 50–70 $ · 2 000–10 000 ≈ 150–250 $.

## Modèle économique
- Pas de publicité (rapporte peu à Madagascar, nuit à un outil de travail).
- Freemium payé par Mobile Money (MVola, Orange Money, Airtel Money).
  - Gratuit : 1 boutique, ~50 commandes / mois.
  - Pro (piste) : 15 000–25 000 Ar / mois ; Business (équipe, livreurs) : 25 000–35 000 Ar.
- Exemple : 50 payants à 25 000 Ar ≈ 1 250 000 Ar de revenu, ≈ 1 070 000 Ar de bénéfice / mois
  (après Mobile Money ~2 %, impôt synthétique ~5 % à confirmer, serveurs), avant marketing.
